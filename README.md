1. ORGANISATION OVERVIEW 

Organisation Name: Minenhle's Kitchen 

History: Minenhle's Kitchen was founded in 2023 in Durban, KwaZulu-Natal. It started as a small home-based business to share authentic Zulu and South African home-cooked meals with the local community. The business grew from selling to neighbours and coworkers to taking weekly meal prep orders. 

Mission: To provide affordable, delicious, and healthy traditional meals made with love, that remind people of home. 

Vision: To become Durban’s most trusted and loved home-cooked meal service. 

Target Audience: Our target audience includes busy families, students, and office workers in the eThekwini area aged 18-50 who want convenient, affordable, and authentic traditional food without cooking. We also target people who miss home-cooked meals. 

2. WEBSITE GOALS & OBJECTIVES 

Goals:  

Increase online orders by 40% within the first 6 months. 

Build brand credibility and showcase our menu professionally. 

Reduce time spent answering "What's on the menu?" WhatsApp messages. 

Key Performance Indicators: 

Number of website visits per month 

Number of orders submitted through the enquiry form 

Click-through rate to WhatsApp from the website 

3. PROPOSED FEATURES & FUNCTIONALITY 

The website will have 5 main pages.  

Homepage: Hero banner, welcome message, and preview of popular dishes with images. 

About Us: Company story, mission, and vision to build trust. 

Menu/Services: A gallery with pictures, descriptions and prices of all meals. 

Order/Enquiry: A form for customers to place orders with name, contact, meal choice and delivery address. 

Contact: Business address, phone number, email, and operating hours. 

The website will be fully responsive for mobile and desktop.

7. PART 2: DESIGNING THE VISUALS & RESPONSIVE DESIGN 

CSS Implementation: A single stylesheet (css/style.css) was built covering the navigation, hero section, menu gallery cards, order form, and footer across all five pages, using CSS custom properties (variables) for the colour palette and consistent spacing. 

Responsive Breakpoints: Two media query breakpoints were implemented — 768px (tablet) and 600px (mobile) — adjusting the navigation layout, centring hero content, collapsing the menu gallery from a multi-column grid to a single column, and stretching the order form and button to full width on small screens. 

Relative Units: Font sizes in the hero heading use clamp() for fluid scaling, and layout spacing/widths use relative and flexible units (rem-based spacing, % and fr-based grid columns) rather than fixed pixel values throughout. 

Responsive Images: Menu item images use the picture element with source media queries for different screen widths, in place of a plain img tag, to meet the responsive image requirement. 

Accessibility: Visible keyboard focus states were added on navigation links, buttons, and form fields. 

Testing: The site was tested across desktop, tablet, and mobile widths using browser resizing and VS Code Live Server before submission.
